---

## 📝 Descrição

Repositório do primeiro curso de automação com Cypress do instrutor **Fernando Papito**, focado em testes E2E de uma aplicação web de cadastro de entregadores:  
➡️ [https://buger-eats.vercel.app/](https://buger-eats.vercel.app/)

---

## 🚀 Resultados Alcançados

- Instalação e configuração dos pré-requisitos, plugins e dependências necessárias para execução do projeto de testes automatizados com Cypress.  
- Entendimento da arquitetura de pastas e arquivos do projeto de testes E2E para aplicações Web com Cypress.  
- Especificação de casos de teste aplicando boas práticas para ampliar a cobertura dos cenários e validar corretamente as regras de negócio.  
- Utilização da linguagem JavaScript e da sintaxe do Cypress para desenvolvimento de testes, com mapeamento de elementos da interface, aplicação do padrão Page Object, criação de *hooks* e validações responsivas.  
- Utilização da biblioteca **Faker** para geração de massa de dados nos testes.  
- Implementação de testes de regressão visual com o plugin `cypress-image-snapshot`, permitindo comparação automática de telas.  
- Utilização do plugin `cypress-file-upload` para testes de upload de arquivos em formulários.
